E-mail HTML code

The full HTML "frame" around every e-mail — for fine-tuning the Design tab doesn't cover (padding, borders, font size, …), without a deploy. Placeholders: {{ '{{BODY}}' }} (required — each e-mail's body goes here), {{ '{{LOGO}}' }}, {{ '{{ACCENT}}' }}, {{ '{{EMOJI}}' }}, {{ '{{SIGNATURE}}' }}, {{ '{{FOOTER}}' }} (these five come from the Design tab). Raw HTML, without the post editor's safety filter (that one can't do the tables/inline styles e-mail needs) — only admins reach this page.
